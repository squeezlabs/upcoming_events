# Updating the squeezlabs demo page

_The_ **squeezlabs** _site draws on this list to populate the demos section._

**Formatting is either:**

`LOCATION | DATE AS SPELLED OUT MONTH, DAY, YEAR`
>e.g., "San Francisco, CA | February 19, 2026"

or if there's a related link:

`LOCATION | [LOCATION NAME](LOCATION LINK) | DATE AS SPELLED OUT MONTH, DAY, YEAR`
>e.g., "San Francisco, CA | [Hardware Pitch Night](https://luma.com/zaxqbap7) | February 19, 2026"
